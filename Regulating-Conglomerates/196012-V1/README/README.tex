\section{Overview}

\begin{itemize}
\item The code in this replication package mainly uses data from four different sources (NBS, 2001-2009, 2011, CMEP, 2001-2010, ATS, 2008-2011, SAIC, 1949-2018)  
\item The package relies on Stata and Matlab code. The code was run using Stata MP Version 18 and Matlab Version R2023b. 
\item The package includes two master files: (1) STATA code \texttt{Do/Master.do} that outputs all exhibits (main paper, online appendix) from STATA, and (2) MATLAB code \texttt{master.m} that outputs three tables (Table 4, Table 5, Table A36) from conducting structural analyses based on estimated data moments. But in terms of execution, (1) \texttt{Do/Master.do} also executes \texttt{master.m} from within do script.
\item Since proprietary data is required to run (1), we provide moment files \\ \texttt{Data\_Moments/Result/Moment*.dta} which were generated by lines 28-65 of \texttt{Do/Master.do} to output final tables and figures. 
\item The package can be expected to run in about 35-40 minutes.
\item Please cite this response when using data and/or code from this replication package.
\end{itemize}

\section{Description of Programs/Code}

{\bf Code} is located in four directories: 
\begin{itemize}
\item \texttt{Data\_Generation\_Program}: This folder contains routines to clean data and produce analysis files that are saved in \texttt{Data} and \texttt{Data\_Moments}. Code in this folder relies on proprietary data.
\item \texttt{Do}: This folder contains routines to produce tables, graphs and scalars that are saved in \texttt{Table}, \texttt{Figure}, \texttt{Appendix\_Table}, \texttt{Appendix\_Figure}, and  \texttt{Scalars} based on analysis data. Code in this folder relies on data in the folder \texttt{Data}.
\item \texttt{Data\_Moments/Do}: This folder contains routines to produce data moments for structural estimation that are saved in \texttt{Data\_Moments/Result}. Code in this folder relies on data in the folder \texttt{Data}.
\item \texttt{Structural\_Analysis}: This folder contains routines to estimate structural analyses and outputs are saved in \texttt{Structural\_Analysis/Output}. Code in this folder relies on estimated data moments in the folder \texttt{Data\_Moments/Result}.
\end{itemize}

\noindent {\bf Master files.} The following master files run all of the analyses in the paper: 
\begin{enumerate}
\item Data Cleaning in Stata (lines 31-70). \texttt{Do/Master.do}: Runs routines to clean data files. This file calls the scripts listed in Table \ref{tab:clean}. This script relies on proprietary data. Replicators with access to proprietary data can find the data in \texttt{Raw\_Data}.
\item Structural Estimation in Matlab. These routines can be called within Stata in lines 72-75 of \texttt{Do/Master.do}. Alternatively, the file \texttt{Structural\_Analysis/master.m} can be used to run the structural estimation routines. This file calls the scripts listed in Table \ref{tab:structural}. This script relies on estimated data moments provided in this archive and located in the folder \texttt{Data\_Moments/Result}.
\item Graphs and Tables in Stata (lines 78-168). \texttt{Do/Master.do}: Generates graphs and tables. This file calls the scripts listed in Table \ref{tab:final}. This script relies on analyses data files provided in this archive and located in \texttt{Data} and (public) raw data in \texttt{Raw\_Data}.
\end{enumerate}

\noindent {\bf Final Outputs} are deposited in the following directories: 
\begin{itemize}
\item Figures and tables are saved in \texttt{Figure}, \texttt{Table}, \texttt{Appendix\_Figure}, and \texttt{Appendix\_Table}.
\item Scalars are saved in \texttt{Scalars}.
\item Outputs from structural estimation are saved in \texttt{Structural\_Analysis/Output}.

\section{Instructions for Replicators} 

The following is the way to replicate the results of the paper:

\begin{itemize}
\item Use the following STATA script to run two master files: \texttt{Do/Master.do}.  Prior to running this program, replicators must set working directories in the following locations: 
\begin{enumerate}
\item Line 16 of \texttt{Do/Master.do}
\item Lines 5 and 6 of \texttt{Structural\_Analysis/define\_directory.m }. Please note the structure of the paths in these lines. Specifically, the new paths should look like \texttt{PATH/Structural\_Analysis} where  \texttt{PATH} is your path. 
\end{enumerate}

\item Also, since MATLAB master script \texttt{Structural\_Analysis/master.m} is run and executed from within \texttt{Do/Master.do}, it is essential for the replicator to specify the exact MATLAB executable in Line 21 of \texttt{Do/Master.do}; otherwise not only \texttt{master.m} but also \texttt{Table2.do}, \texttt{TableA24.do}, and \texttt{TableA38.do} will not run properly. 
\begin{enumerate}
\item For most cases, specifying Line 21 as follows will work: \texttt{global matlab "!matlab"}
\item For cases where the following errors are raised (\texttt{zsh commmand not found:matlab}), it means that UNIX/Terminal could not locate MATLAB executable. In this case, it is important for replicator to specify the path of matlab executable. For MacOS users with MATLAB R\_2023b, for example, Line 21 should be as follows: \\ \texttt{global matlab ``!/Applications/MATLAB\_R2023b.app/bin/matlab''}
\end{enumerate}

When setting working directories please be mindful of noting when a directory ends with a forward slash (i.e., ``/'') and when it does not, as this may impede the code from running correctly.
