
This folder contains the files that conduct all the structural analysis

---Estimation: run Main.m to estimate parameters of the baseline model and to compare model fits

---Estimation Menu: run Main.m to estimate parameters for alternative combinations rho/sigma

---Sensitivity Analysis: run Main_ste.m for standard errors of baseline model
			 run Main_ste_menu.m for standard errors of alternative combinations rho/sigma

---Estimation ImpSub: run Main.m to estimate parameters for model with imperfect substitution
		      run Main_ste.m for standard errors of imperfect substitution

---Counterfactual Baseline: run Main.m to solve the baseline counterfactual and the decomposition of DID
			    run Main_compare.m to solve for alternative regulations

---Counterfactual Robustness: run Main_compare.m for all the alternative values of rho/alpha. 

---Counterfactaul AdjK: run Main.m to solve the counterfactual with capital adjustment

---Imperfect Sub: run Main.m to solve for the case of imperfect substitution

---Energy Efficiency: run Main.m to solve for the case of endogenous energy efficiency cost

---Heterogeneous EE: run Main.m and Main_robust to solve for the case of heterogeneous energy efficiency (ex-ante)

---No Conglomerate: run Main.m  to solve for the case of no conglomerates and associated related-firm spillovers
		  
---Output: load all the above saved files and generate Table4, Table5 and Table36 in latex
