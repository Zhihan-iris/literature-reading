研究设计工作坊

从两家工厂的小模型，
到一篇完整的论文

“把话题写丰满”意味着逐步补足一个结论需要的证据。每次扩展都应解决前一个版本解释不了的问题，并产生能够检验或量化的新含义。

以下是根据本文提炼的教学路线，不是作者真实研究过程的还原。两厂模型、公式和交互数字是独立教学推导，并非原文结构模型或原文估计结果。
回到逐页写作拆解开始从零搭建写自己的研究提纲

00

只有一个话题时，先找决策矛盾

“节能政策的效果”只是领域，不是一个已经明确的研究问题。先把它变成一个选择问题：谁被约束？他可以在哪些行为之间选择？哪些选择没有被常规评价记录？这些遗漏会改变什么结论？

最初的想法多问一步得到的研究对象
政府要求企业节能企业是提效、减产，还是转移生产？不同应对边际及其成本
大企业能耗下降关联企业和竞争者是否增加能耗？直接效果与两类溢出
总体能耗减少减少多少，付出什么经济代价？加总与福利权衡
现有监管有扭曲换一个监管单位是否改善权衡？机制对应的政策反事实

第一张纸上应该有什么

写一个具体场景、两个可能机制、一个能区分它们的预测，以及一项可能获得的数据。此时不需要把所有机制都纳入模型。先证明研究问题有一个可以被回答的部分。

最小可行问题

在能耗配额下，受管企业的能耗下降是否伴随产出同步下降？这个问题还不是全文，但它能把“节约能源”与“提高能效”分开。

01

先用一个固定订单模型，证明配置扭曲可能存在

假设一个老板拥有 A、B 两厂，总订单为 Q，必须完成。两厂成本分别为 CA(qA) = a qA²/2、CB(qB) = b qB²/2，其中 a、b > 0。二次成本意味着追加产量越来越贵。为隔离配置机制，暂定每单位产品消耗相同的能源。

min a qA²/2 + b qB²/2
满足 qA + qB = Q

无监管时，成本最小化要求两厂边际成本相等：a qA = b qB。联立总订单约束即可得到：

qA* = bQ/(a+b)，　qB* = aQ/(a+b)

若政府只限制 A，要求 qA ≤ q̄，且 q̄ < qA*，老板只能令 qA = q̄、qB = Q − q̄。此时 B 的边际成本比 A 更高，继续让 B 承接订单虽然昂贵，却是满足 A 的限制所必需的。

额外成本 = (a+b)(q̄ − qA*)²/2

这个表达式可以通过把 qB = Q − qA 代入成本函数并配方得到。它告诉我们，偏离原来最优配置越远，成本增加越快。

这个模型已经做到什么？还做不到什么？

它已经展示单厂监管可能造成内部配置扭曲。但因为总订单固定，A 少生产的部分会全部转到 B；又因为单位产出耗能相同，总能耗完全不变。它因此无法解释论文中“不完全承接”和“净节能”。这不是需要掩饰的问题，而是下一次扩展的明确任务。

02

让集团总产出可以变化，得到不完全转移

现在取消固定订单，允许老板在卖多少与生产成本之间选择。设集团面对逆需求 p(Q) = v − dQ，其中 v、d > 0，Q = qA + qB。价格越高，愿意购买的数量越少。

max [v − d(qA + qB)](qA + qB)
− a qA²/2 − b qB²/2

无约束时，两厂边际成本仍相等。记 H = 1/a + 1/b，可以解出集团边际收入 m = v/(1 + 2dH)，进而 qA* = m/a、qB* = m/b。现在施加对 A 的有效上限 q̄ < qA*，并假设 B 仍有正产出：

qB = (v − 2d q̄)/(b + 2d)

这来自 B 的一阶条件：v − 2d(q̄ + qB) = b qB。对上限求导：

dqB/dq̄ = −2d/(b+2d)，
dQ/dq̄ = b/(b+2d) > 0

因此，收紧 A 的上限，会使 B 扩张，但承接量小于 A 的减产量，集团总产出仍下降。需求不再固定后，“部分转移”成为企业权衡后的结果。在当前同等单位耗能假设下，总产出下降也意味着总能耗下降。

注意：这里说明一种能够产生部分转移的最小机制。它不证明真实企业面临线性需求和二次成本，也不替代原文含资本、关联企业数量及行业价格反馈的模型。

亲手改变一个参数

教学模型，默认 v = 100、a = 1、d = 1。滑块范围保持对 A 的约束有效且两厂均有正产出。

观察 b 增大时发生什么：B 扩张越来越昂贵，承接比例 2d/(b+2d) 下降。一个参数因此同时改变行为预测与可用于识别它的数据特征。

03

从一个结果，扩展成可区分机制的证据链

假设现在只得到“受管企业能耗下降”。不要立刻增加十个分组回归。先写出竞争解释，再寻找它们预测不同的变量或对象。

解释还应该看到什么？什么证据会削弱它？
技术提效给定产出所需能源下降产出与能源同步收缩、能效改善很小
纯粹减产受管企业产出下降同集团可替代企业明显扩张
集团内部转移可替代生产的关联企业扩张无论产品是否相似，所有关联企业都同样增长
集团共同利好不同业务的关联企业也可能受益增长主要集中于同一细分行业
市场需求重配强监管行业的无关企业也扩张只在所有权网络内部有反应

这些比较不是严格的一对一证明。例如，产值能效受价格影响，安慰剂行业也可能有不同趋势。因此要把“与某机制一致”“减弱某种解释”和“识别出唯一机制”区别开。真实论文通常通过多项有限但互补的证据积累可信度。

让每项扩展都承担一个任务

机制：解释结果为何发生。异质性：检验机制在什么条件下更强。稳健性：判断结果是否由测量、样本或设定驱动。三者可以交叉，但不能全部统称为机制。比如把同一结果换一个回归软件，并没有检验经济机制。

04

只有问题需要时，才加入市场均衡与结构估计

两厂模型只描述一个集团。要解释无关竞争者的扩张，需要给其他集团一个生产选择，并让市场价格由整体供需决定。此时“对照组也受到影响”不再只是麻烦，而是必须解释的事实。

新加入的结构解决哪个旧问题？需要什么额外纪律？
多个集团和产品替代无关企业为何扩张需求弹性、市场边界与价格证据
规模与效率异质性为什么企业大小差别很大企业规模分布及投入产出份额
集团内多个关联企业为什么有的集团更能承接生产网络定义和内部规模分布
短期固定资本为什么不能马上复制生产能力时间窗口与调整成本的合理性
统一求解的新价格为什么微观相对效应不能直接加总一致的市场出清条件与样本外验证

原文按这些需要构造了一个可与数据连接的模型。但并不是所有项目都应该沿着同一条路线走到底。如果你的问题只涉及一个清楚的局部效应、没有重要均衡反馈，也可以用更小的模型和更扎实的实证写成完整论文。

扩展的停止条件

新增结构没有新预测；参数无法得到数据约束；计算复杂性明显上升却不影响结论；或者新政策比较需要超出数据支持范围的行为假设。出现这些情况，应先停止扩展并重新缩小问题。

05

从模型输出进入福利与政策，必须补充评价标准

“节能更多”与“政策更好”不是同一句话。要比较福利，必须说明环境损害、消费购买力、税收收入和其他渠道如何进入评价。本文选择报告政府支付意愿门槛，使读者知道在什么价值判断下政策值得。

一个有针对性的反事实应修复前面发现的扭曲。本文的集团监管不是凭空提出：既然单厂配额扰乱集团内部配置，就让集团在总约束下选择配置。比较时保持价格成本一致，再看能源节约能提高多少。

写丰满的关键，是每一步都有不可省略的理由

看到直接效果：受管企业能耗下降。
追问实现方式：是否只是减产？
追问活动去向：集团内部是否承接？
追问未承接部分：其他竞争者是否扩张？
追问总体效果：有两类溢出时净节能多少？
追问是否划算：节能收益能否补偿经济成本？
追问怎样改善：换监管单位能否修复已识别的扭曲？

研究往往会反复试错，并不按这个顺序真实发生。写作可以把已经完成的工作重新组织成这一顺序，让读者每读完一节都知道：下一节为什么有必要。

把一个结果写成完整段落

一段有论证功能的结果文字，通常可以包含：本段问题、设计或比较、发现、经济解释、解释边界，以及下一步需要补充什么。并非每段必须写满六句，但重要段落最好让这些关系清楚。

受监管企业的能源使用相对下降，但这一变化本身不足以说明是否发生效率改善。我们因此同时比较产出和能效的变化。两者的结果与企业通过压缩生产满足配额一致，而未显示显著的额外能效改善。由于产值能效还可能受到价格和能源测量的影响，这一发现应限于本文的观测口径。它进一步提出一个问题：受管企业减少的生产是否转移到了同集团的其他企业？

教学性示范段落，不是原文翻译。比较、结果与限制分别对应正文 §II 及数据讨论。

从初稿到可用稿

初稿：“政策效果显著，因此政策很好。”缺少结果变量、比较对象、机制与福利标准。

改进：“受管企业能耗相对于对照组下降。”明确了估计对象，但仍无法判断实现方式。

再推进：“能耗和产出相对下降，而能效未出现显著额外改善，因此还需检验生产重配。”现在它能自然引出下一节。

把方法迁移到你自己的题目

下面的提纲只保存在当前浏览器，不上传到服务器。可以导出 Markdown，再拿去写研究计划或与老师讨论。不同浏览器和设备之间不会自动同步。

判断一项扩展是否值得做

值得推进的理由需要停下来检查的信号
解决主结果留下的具体疑问只是因为其他论文也做了这一项
产生能与竞争解释区分的预测任何结果都可以事后解释为支持机制
新增参数有对应数据约束靠自由参数把所有图都拟合到一致
改变政策效果的解释或比较数学复杂了，但结论没有更清楚
有失败标准并保留边界只展示显著结果和成功拟合

你可以把“如何写丰满”改成一个更可操作的目标：让每个重要结论都有足够的证据，让每个下一步都来自一个真实的未解问题。篇幅会随着必要的论证增长。
