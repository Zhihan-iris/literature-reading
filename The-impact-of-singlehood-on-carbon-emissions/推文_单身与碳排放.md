# 一人独居，碳排翻倍？来自中国的证据

## 📌 研究背景

随着全球气候变化的加剧，减少家庭碳排放成为实现中国"双碳目标"的关键抓手。2024年全球能源相关碳排放达376亿吨，中国以126亿吨占全球三分之一。与此同时，中国单身人口比例持续上升——从2001年的25.9%升至2023年的28.8%。**那么，单身率上升究竟是增加还是减少了人均碳排放？** 这一问题在学术界存在明显分歧：韩国数据显示单人家庭因居住面积小反而降低了人均排放，而日本数据则表明单人家庭因高能源消耗和服装、医疗等消费支出的增加反而提高了碳足迹。

这篇发表在《Journal of Cleaner Production》上的研究首次利用中国大规模面板数据，系统分析了单身率对人均碳排放的影响及其作用机制。

---

## 📌 文献回顾与研究假设

### 已有研究的空白

现有文献在三个层面存在不足：

1. **宏观视角主导**：传统碳排放研究主要关注产业结构、能源消费、技术进步等宏观因素，对人口结构变化的关注不足
2. **视角局限**：少数关于单人家庭的研究主要聚焦于发达国家（韩国、日本），缺乏来自最大碳排放国且处于"第二次人口转变"中的中国的证据
3. **机制不清**：尚无研究系统揭示单身通过哪些路径影响碳排放

### 理论机制与研究假设

文章从三个维度提出了单身影响碳排放的理论机制：

**假设 H1：单身率对人均碳排放有显著正向影响**

**假设 H2：单身率通过三条路径影响人均碳排放**

$$单身率 \uparrow \Rightarrow \begin{cases} \text{路径一：高价值共享资产规模经济效应} \downarrow \\ \text{路径二：生活能源共享程度} \downarrow \\ \text{路径三：便利性消费倾向} \uparrow \end{cases} \Rightarrow \text{人均碳排放} \uparrow$$

## 📌 数据与方法

### 3.1 数据来源

研究使用 **中国家庭追踪调查（CFPS）** 数据，该调查由北京大学社会科学调查署实施，覆盖25个省/市/自治区，目标样本约16,000户。研究利用2010年至2022年七轮调查数据，最终构建了包含 **63,412户** 的不平衡面板数据集。

### 3.2 主要变量

| 变量类型 | 变量名称 | 定义 |
|---------|---------|------|
| **被解释变量** | ln(pcarbon) | 人均碳排放（对数），由家庭碳排放除以家庭规模得到 |
| **核心解释变量** | singlehood | 家庭单身率，即20岁及以上未婚/离婚/丧偶成员占家庭总人口的比例 |
| **控制变量** | — | 户主特征（年龄、性别、城乡户籍、政治面貌、受教育年限、就业状态等）和家庭特征（家庭规模、老龄化率、抚养比、家庭收入、家庭净资产等）|

### 3.3 碳排放测算方法

#### 投入产出法的基本原理

研究采用 **投入产出法（Input-Output Method）** 计算家庭消费碳排放。相比生命周期评估（LCA）方法，投入产出法规避了LCA对微观过程数据的高依赖性问题，尤其适用于发展中国家底层统计数据不完整的场景。

核心逻辑是将家庭消费支出与部门碳排放账户相连接，分两步实现：

**第一步：消费-行业映射**

将家庭消费支出按官方分类标准划分为8大类，并与42个相关工业部门建立对应关系：

| 消费类别 | 对应工业部门 |
|---------|------------|
| 食品、烟酒 | 农副产品食品加工、食品制造、饮料制造、烟草等 |
| 衣着 | 纺织业、纺织服装鞋帽制造、皮革毛皮羽毛制品等 |
| 居住 | 建筑业、电力热力燃气水生产供应 |
| 家庭设备及服务 | 木加工、家具制造、电气机械、金属制品、塑料制品 |
| 交通通信 | 交通运输设备、通信设备计算机等电子设备、运输服务、邮政服务 |
| 教育文化娱乐 | 教育文化娱乐、造纸印刷、工艺美术等 |
| 医疗保健 | 医药制造业 |
| 其他商品服务 | 批发零售、住宿餐饮、手工艺等 |

**第二步：碳排放强度系数标定**

标准煤排放因子统一将各种能源消费折算成标准煤当量，具有数据可得性好、跨区域可比的优势。碳排放强度由能源强度与标准煤排放系数相乘得到：

$$CI_i = w \times \frac{\sum_{n=1}^{N} Ind_{n,i}}{\sum_{n=1}^{N} \Delta_{n,i}}$$

其中：
- $CI_i$：第i类消费品的碳排放强度（kgCO₂/元）
- $w$：标准煤排放系数，取值2.493
- $Ind_{n,i}$：第i类消费 category 中第n行业的标准煤消耗量（kgce）
- $\Delta_{n,i}$：第i类消费 category 中第n行业的总产值（元）
- $N$：第i类消费 category 所含行业总数

**第三步：家庭碳排放计算**

$$CE = \sum_{i=1}^{8} (CS_i \times CI_i)$$

其中：
- $CE$：家庭总碳排放量（kgCO₂）
- $CS_i$：家庭在第i类消费上的支出（元）
- $CI_i$：第i类消费的碳排放强度（kgCO₂/元）

由此得出8类消费的碳排放因子（单位：kgCO₂/元）：

| 消费类别 | 碳排放因子 |
|---------|----------|
| 食品 | 0.418 |
| 衣着 | 0.561 |
| 居住 | 0.708 |
| 家庭设备及服务 | 0.484 |
| 交通通信 | 0.827 |
| 教育文化娱乐 | 0.427 |
| 医疗保健 | 0.256 |
| 其他商品服务 | 0.190 |

### 3.4 回归模型设定

研究采用 **县-时间双向固定效应面板模型**：

$$\ln(percarbon_{it}) = \beta_0 + \beta_1 \cdot singlehood_{it} + \sum_{k=1}^{K} \gamma_k \cdot control_{k,it} + \mu_i + \lambda_t + \varepsilon_{it}$$

其中：
- 被解释变量：$\ln(percarbon_{it})$ —— 第i县第t年人均碳排放的对数
- 核心解释变量：$singlehood_{it}$ —— 第i县第t年的家庭单身率
- 控制变量：$control_{k,it}$ —— 第i县第t年第k个控制变量
- $\mu_i$ —— 县级固定效应，吸收不随时间变化的地区特征
- $\lambda_t$ —— 时间固定效应，捕捉全国性政策冲击
- $\varepsilon_{it}$ —— 随机误差项，服从i.i.d.正态分布

**固定效应选择的合理性：**

- 县固定效应消除省级汇总偏差，吸收地区固有特征
- 时间固定效应捕捉全国性政策与宏观冲击
- 利用县内时间变化满足严格外生性要求

## 📌 研究结果

### 4.1 基准回归结果

基准回归中，单身率对人均碳排放对数的影响系数为 **0.244**，在1%水平上显著。由于单身率是0到1之间的比例变量，更严谨的读法是：单身率每上升1个百分点，约对应人均碳排放增加0.244%。分婚姻状态看，未婚率系数最高（0.323），离婚率次之（0.309），丧偶率最弱（0.065）。未婚人群排放高于离婚/丧偶人群的原因在于：未婚者往往收入更高、消费更享乐化、更集中于高碳密集型服务体系的特大城市。

### 4.2 稳健性检验

**替换被解释变量**：用电量数据计算的用电碳排放进行回归，单身率影响系数为0.168，低于基准的0.244，说明仅用电量会低估单身率的影响。

**替换核心解释变量**：设置"单身率>0"和"完全单身（单身率=1）"两个虚拟变量，两者均显著为正，且完全单身组的系数更大，说明单身程度越高、碳排放越多。

**去除疫情样本**：剔除2020年样本后结果依然稳健。

### 4.3 内生性处理

采用 **县级平均单身率** 作为工具变量进行两阶段最小二乘法（2SLS）回归。第一阶段F统计量为7953.11（远大于10），K-P rk LM检验p值为0.0000，弱工具变量检验统计量为6431.774（远超临界值），工具变量有效性得到确认。工具变量回归结果显示影响系数升至0.306，说明存在由反向因果导致的向下的偏误。

### 4.4 机制分析

#### 路径一：高价值共享资产规模经济效应

单身导致家庭数量增加、共享程度下降，高价值资产的规模经济效应减弱：

| 中介变量 | 单身率→中介变量 | 中介变量→人均碳排放 |
|---------|--------------|-------------------|
| 人均住房面积 | +0.352*** | +0.160*** |
| 人均住房套数 | +0.427*** | +0.653*** |
| 人均汽车数量 | +1.509*** | +0.133*** |
| 人均购车支出 | +0.609*** | +0.230*** |

控制人均住房套数后，单身率对人均碳排放的影响变得不显著，表明 **人均住房套数完全中介了单身率对碳排放的影响**。

#### 路径二：便利性消费

单身群体因独居做饭成本效益低而更倾向外出就餐，因缺乏共享而更依赖家具耐用消费品和网购，因远程社交需求而手机费用更高：

| 中介变量 | 单身率→中介变量 | 中介变量→人均碳排放 |
|---------|--------------|-------------------|
| 人均外出餐饮支出 | +0.605*** | +0.332*** |
| 人均家具耐用品支出 | +0.334*** | +0.191*** |
| 人均网购支出 | +0.617*** | +0.074*** |
| 人均手机费用 | +0.169*** | +0.280*** |

#### 路径三：生活能源共享

单身导致厨房燃料、冬季供暖、家电使用的人均能源消耗上升，形成链式中介：

| 中介变量 | 单身率→中介变量 | 中介变量→人均碳排放 |
|---------|--------------|-------------------|
| 人均燃料费 | +0.255*** | +0.192*** |
| 人均供暖费 | +0.358*** | +0.201*** |
| 人均电费 | +0.237*** | +0.163*** |

## 📌 研究结论与政策建议

### 主要结论

1. **基准结论**：单身率上升显著增加人均碳排放，影响系数为0.244（工具变量法校正后为0.306）
2. **三条机制**：高档共享资产规模经济效应下降、生活能源共享不足、便利性消费增加
3. **异质性特征**：男性、农村、青年、高收入和高学历群体的单身率影响更为突出

### 政策建议

**一、个人碳预算制度（Personal Carbon Budget）**

通过设定公民碳排放上限，促使单身家庭审视并改变消费行为。政策设计应充分考虑单身群体的特殊性，制定差异化的碳配额标准或针对性激励措施，避免"一刀切"造成的不公平负担。

**二、发挥学习曲线效应**

利用城市数字化环境优势，帮助单身群体快速学习和适应低碳生活：

- 建立**国家级"个人低碳生活数字助手"平台**，集成智能电表和交通数据，实时追踪碳足迹并提供具体建议
- 设立**社区低碳生活实验室**，提供智能家居体验区、技能工坊、资源共享角落等实体场景
- 构建**绿色积分体系**，将节能行为、知识获取和社区参与量化为积分，可兑换公共服务或商业优惠

**三、在敏感干预点精准施策**

在租房、购买家电、购车等关键决策时点主动推荐低碳替代方案（如合租公寓、能效家电、新能源车），并配以优惠券激励，将低碳选择嵌入消费决策流程。

**四、构建包容性低碳支持体系**

政策的核心目标是赋予所有公民（不论婚姻状况）向低碳生活过渡的能力和选择权，而非干预个人生活方式。具体包括：

- 研发适合小户型的节能家电和模块化家具
- 在社区层面发展共享经济（公共厨房、共享洗衣房、工具图书馆）
- 优化城市规划，增加小户型保障房供给，完善公共交通和慢行网络
- 开展面向全社会的低碳生活公众教育

## 📌 研究局限与未来方向

1. **数据粒度不足**：未能区分化石与非化石能源消费，未来需结合生命周期评估方法细化直接碳排放测算
2. **微观行为机制受限**：未来可通过详细调查、实验或大数据深入研究单身群体在居住、交通、消费等具体场景下的能源使用行为
3. **跨文化比较缺失**：未来应开展欧洲、北美、东亚等不同文化背景下的比较研究，探究文化价值观和社会保障体系的调节作用
4. **政策模拟空白**：未来需对各项干预措施进行政策模拟和成本效益分析，提供量化的政策设计依据

---

> **核心发现**：单身率每上升1个百分点，人均碳排放约增加0.244%；其背后是共享经济效应减弱、能源利用效率下降和便利性消费增加三条机制共同作用的结果。
