理论模型：大跃进期间的中央计划动态模型

1. 基本设定

1.1 经济结构

  • 两部门：农业（生产粮食）与工业（生产工业品）。
  • 劳动力：全国总劳动力标准化为 1。
    • $L_t$：第 $t$ 期农业部门劳动力比例，$0 \le L_t \le 1$。
    • $1 - L_t$：工业部门劳动力比例。

1.2 农业生产

仅使用 有效劳动 作为投入，生产函数为：

$$Q_t = a \cdot L_t \cdot h_t$$
🔗

其中：

  • $Q_t$：第 $t$ 期粮食总产量。
  • $a$：农业全要素生产率（受技术和组织影响）。
  • $h_t$：每个农业劳动者的 工作能力（体力）。

工作能力与营养的关系：

$$h_t = f(c_t), \quad f'(c_t) > 0$$
🔗

$c_t$ 为第 $t$ 期每个农民实际消费的粮食。论文采用具体函数形式 $f(c) = c^{\delta}$（$\delta > 0$）。

1.3 工业生产

  • 列昂惕夫（Leontief）技术：生产 1 单位工业品需要：
    • 1 单位劳动
    • $m$ 单位粮食作为中间投入
  • 工业部门还需要养活工业工人：每个工业工人消费 $n$ 单位粮食。
  • 因此，工业部门的 总粮食需求 为：
$$m(1-L_t) + n(1-L_t) = (m+n)(1-L_t)$$
🔗

1.4 粮食征购与约束

政府从每个农民手中征购 $p_t$ 单位粮食，总征购量：

$$p_t L_t$$
🔗

粮食供给约束（工业部门能正常运行的必要条件）：

$$p_t L_t \ge (m+n)(1-L_t)$$
🔗

在最优决策中，通常取等号（紧约束）。

1.5 农民留存粮食与消费动态

每个农民的平均产出：

$$\frac{Q_t}{L_t} = a f(c_t)$$
🔗

农民留存粮食（用于未来消费）：

$$g_t = a f(c_t) - p_t$$
🔗

第 $t+1$ 期的消费等于第 $t$ 期的留存：

$$c_{t+1} = g_t = a f(c_t) - p_t \tag{1}$$
🔗

2. 政府的目标函数

政府只关心 工业产出的贴现值之和：

$$\max \sum_{t=0}^{\infty} \beta^t (1 - L_t), \quad \beta \in (0,1)$$
🔗

这里 $\beta$ 是政府的贴现因子（$\beta$ 越小，政府越没有耐心）。

利用紧约束 $p_t L_t = (m+n)(1-L_t)$，可以消去 $p_t$ 和 $L_t$，将问题转化为关于消费 $c_t$ 的动态规划。

从约束中解出 $L_t$：

由 $p_t L_t = (m+n)(1-L_t)$ 可得：

$$p_t = \frac{(m+n)(1-L_t)}{L_t}$$
🔗
下一步 →

代入 (1) 式：

$$c_{t+1} = a f(c_t) - \frac{(m+n)(1-L_t)}{L_t}$$
🔗
← 上一步下一步 →

解出 $L_t$：

$$\frac{(m+n)(1-L_t)}{L_t} = a f(c_t) - c_{t+1}$$
🔗
← 上一步下一步 →
$$\Rightarrow \frac{1-L_t}{L_t} = \frac{a f(c_t) - c_{t+1}}{m+n}$$
🔗
← 上一步下一步 →
$$\Rightarrow \frac{1}{L_t} - 1 = \frac{a f(c_t) - c_{t+1}}{m+n}$$
🔗
← 上一步下一步 →
$$\Rightarrow L_t = \frac{m+n}{a f(c_t) - c_{t+1} + m+n}$$
🔗
← 上一步下一步 →

于是工业产出：

$$1 - L_t = \frac{a f(c_t) - c_{t+1}}{a f(c_t) - c_{t+1} + m+n} \tag{2}$$
🔗
← 上一步下一步 →

重写目标函数：

将 (2) 代入政府目标，得到：

$$U = \sum_{t=0}^{\infty} \beta^t \cdot \frac{a f(c_t) - c_{t+1}}{a f(c_t) - c_{t+1} + m+n} \tag{3}$$
🔗
← 上一步进入第 3 节 →

其中 $c_0$ 给定，控制变量为序列 $\{c_1, c_2, \dots\}$。

3. 欧拉方程的推导

3.1 定义函数

令

$$F(x, y) = \frac{a f(x) - y}{a f(x) - y + m+n}$$
🔗
下一步 →

则目标函数为：

$$U = \sum_{t=0}^{\infty} \beta^t F(c_t, c_{t+1})$$
🔗
← 上一步进入 3.2 →

3.2 一阶条件

对某个内部 $c_t$（$t \ge 1$）求导：

$$\frac{\partial}{\partial c_t} \left[ \beta^{t-1} F(c_{t-1}, c_t) + \beta^t F(c_t, c_{t+1}) \right] = 0$$
🔗
下一步 →

除以 $\beta^{t-1}$ 得：

$$\frac{\partial F(c_{t-1}, c_t)}{\partial c_t} + \beta \frac{\partial F(c_t, c_{t+1})}{\partial c_t} = 0 \tag{4}$$
🔗
← 上一步进入 3.3 →

3.3 计算偏导数

记 $D(x,y) = a f(x) - y$，则 $F(x,y) = \dfrac{D}{D + m+n}$。

对第二个变量求偏导：

$$\frac{\partial F}{\partial y} = \frac{-1 \cdot (D+m+n) - D \cdot (-1)}{(D+m+n)^2} = \frac{-(m+n)}{(D+m+n)^2}$$
🔗
下一步 →

对第一个变量求偏导：

$$\frac{\partial F}{\partial x} = \frac{a f'(x) \cdot (D+m+n) - D \cdot a f'(x)}{(D+m+n)^2} = \frac{a f'(x) (m+n)}{(D+m+n)^2}$$
🔗
← 上一步进入 3.4 →

3.4 代入一阶条件

在 (4) 中：

$$\frac{\partial F(c_{t-1}, c_t)}{\partial c_t} = \frac{-(m+n)}{\bigl( a f(c_{t-1}) - c_t + m+n \bigr)^2}$$
🔗
下一步 →
$$\frac{\partial F(c_t, c_{t+1})}{\partial c_t} = \frac{a f'(c_t) (m+n)}{\bigl( a f(c_t) - c_{t+1} + m+n \bigr)^2}$$
🔗
← 上一步下一步 →

代入 (4) 并消去 $(m+n)$：

$$\frac{-1}{\bigl( a f(c_{t-1}) - c_t + m+n \bigr)^2} + \beta \cdot \frac{a f'(c_t)}{\bigl( a f(c_t) - c_{t+1} + m+n \bigr)^2} = 0$$
🔗
← 上一步下一步 →

整理得：

$$\beta \cdot \frac{a f'(c_t)}{\bigl( a f(c_t) - c_{t+1} + m+n \bigr)^2} = \frac{1}{\bigl( a f(c_{t-1}) - c_t + m+n \bigr)^2}$$
🔗
← 上一步下一步 →

两边取倒数：

$$\frac{\bigl( a f(c_t) - c_{t+1} + m+n \bigr)^2}{\bigl( a f(c_{t-1}) - c_t + m+n \bigr)^2} = \beta a f'(c_t)$$
🔗
← 上一步进入 3.5 →

3.5 得到标准形式

将下标 $t$ 替换为 $t+1$，得到论文中的欧拉方程：

$$a\beta f'(c_{t+1}) = \left[ \frac{ a f(c_{t+1}) - c_{t+2} + m+n }{ a f(c_t) - c_{t+1} + m+n } \right]^2 \tag{5}$$
🔗
← 上一步进入第 4 节 →

4. 稳态分析

稳态 定义：所有变量不随时间变化，即

$$c_t = c_{t+1} = c_{t+2} = \tilde{c}$$
🔗

将稳态代入欧拉方程 (5)：

  • 右边分子分母相同，比值为 1，平方后仍为 1。
  • 左边为 $a\beta f'(\tilde{c})$。

因此：

$$a\beta f'(\tilde{c}) = 1 \quad \Longrightarrow \quad f'(\tilde{c}) = \frac{1}{a\beta} \tag{6}$$
🔗

4.1 稳态的经济含义

  • 由于 $f''(c) < 0$（凹性），方程 (6) 有唯一解 $\tilde{c}$。
  • 更耐心的政府（$\beta$ 较大）→ 右边 $1/(a\beta)$ 较小 → $f'(\tilde{c})$ 较小 → $\tilde{c}$ 较大。
    即政府越有耐心，农民稳态消费越高。
  • 农业生产率提高（$a$ 增大）→ 类似效果，稳态消费增加。

4.2 稳态下的其他变量

  • 稳态工作能力：$\tilde{h} = f(\tilde{c})$。
  • 稳态人均产量：$\tilde{q} = a \tilde{h}$。
  • 稳态农业劳动力比例 $\tilde{L}$ 可由紧约束解出，但论文未显式给出。

4.3 稳定性

由 $f''<0$ 及动态系统的性质，可以证明（通过线性化）稳态是 渐近稳定的：偏离稳态的最优路径会逐渐收敛回 $\tilde{c}$。

5. 数值模拟与政策冲击（论文图 1）

5.1 参数校准（附录 B）

  • $\beta = 0.9$（基准耐心程度）
  • 营养函数：$h = c^{0.85}$（$\delta = 0.85$）
  • $a = 1.8465$，$m+n = 27.6471$，使稳态 $c=10$，农业劳动力占比 90%。

5.2 大跃进冲击

  • 第 1–4 年：经济从低消费（$c=8$）向稳态恢复。
  • 第 5 年：政府发动大跃进，同时发生两个变化：
    1. 不耐烦程度增加：$\beta$ 从 0.9 降至 0.8。
    2. 错误预期：认为集体化使 $a$ 永久提高 50%（实际永久下降 2%）。
  • 第 6 年起：政府意识到错误，恢复 $\beta=0.9$ 并接受真实 $a$。

5.3 模拟结果

  • 农业劳动力 $L_t$：第 5 年骤降，第 6 年回升。
  • 人均消费与征购：第 5 年征购激增，消费暴跌；第 6 年消费最低。
  • 工作能力 $h_t$：紧跟消费变化，第 6 年触底。
  • 总产量 $Q_t$：第 5 年开始下降，第 6 年继续恶化，之后缓慢恢复，但稳态水平低于震前（因实际 $a$ 永久下降）。

模拟动态与实际数据（表 1、表 2）高度一致。

6. 模型的核心结论

  1. 资源转移：政府错误认为农业生产率会大幅提高，于是将劳动力从农业转移到工业。
  2. 过度征购：政府变得不耐烦，为了提高当前工业产出，大幅提高人均征购量。
  3. 营养反馈：过度征购导致农民口粮严重不足 → 体力下降 → 劳动生产率下降 → 总产出崩溃。
  4. 系统性风险：中央计划下信息扭曲 + 缺乏制衡 + 营养‑劳动反馈机制，使得一个"理性"的政府也可能酿成灾难。

以上就是 理论模型及详细推导 的完整整理。
